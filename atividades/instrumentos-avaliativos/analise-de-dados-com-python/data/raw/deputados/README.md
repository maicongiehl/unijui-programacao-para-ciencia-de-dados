### Coleta de Dados Automatizada (Web Scraping)

Para a obtenção da base histórica de deputados, foi desenvolvido um script de automação utilizando **Selenium** e **WebDriver Manager**. 

O script acessa diretamente a página do dataset na [Base dos Dados](https://basedosdados.org/dataset/3d388daa-2d20-49eb-8f55-6c561bef26b6?table=d37931b4-8b67-47c7-b910-014695dc8f36), navega dinamicamente pela interface web clicando nas abas de download e aciona o arquivo da tabela correspondente.
