## Definição do Problema

Motivado pelo recente cenário eleitoral federal, este projeto investiga a atuação dos deputados federais no período de 2023 a 2026. 

O objetivo é analisar a **"eficiência" parlamentar** por meio da relação entre a produção legislativa e os custos da atividade parlamentar (Cota Parlamentar). Para isso, o estudo cruza dados de:
* Deputados federais e suas respectivas despesas;
* Partidos políticos e suas orientações ideológicas;
* Propostas de leis apresentadas.
